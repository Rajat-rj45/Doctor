# MarizFirst MVP Scope Lock

1. Public Website
   - Home
   - Doctors
   - Hospitals
   - Clinics
   - Specialities
   - Cities
   - Blog
   - Contact
   - Partner With Us
   - Legal pages

2. Search + Discovery
   - Doctor search
   - Hospital search
   - Clinic search
   - Speciality search
   - City and area filtering
   - Mobile filter drawer

3. Doctor Profiles
   - Profile image
   - Qualification
   - Experience
   - Registration number
   - Speciality
   - City/location
   - Consultation fee
   - Slots
   - FAQ
   - SEO metadata
   - Booking CTA

4. Hospital/Clinic Profiles
   - Facilities
   - Gallery
   - Linked doctors/team
   - Address
   - Map link
   - CTA
   - SEO metadata

5. Booking Engine
   - Slot selection
   - Short patient form
   - Consent
   - Pending Confirmation status
   - Lead creation
   - Source tracking

6. Admin Panel
   - Listings
   - Appointments
   - Leads
   - Partners
   - Content
   - SEO
   - Media
   - Notifications
   - Audit logs

7. Partner Dashboard
   - Own profile
   - Slot management
   - Appointment accept/reject/reschedule
   - Completion/no-show update
   - Basic reports

8. WhatsApp Notifications
   - Patient acknowledgement
   - Admin alert
   - Partner alert
   - Confirmation
   - Reschedule
   - Cancellation
   - Reminder
   - Logs and retry

9. SEO Architecture
   - Dynamic metadata
   - Sitemap
   - Robots
   - Schema
   - Canonical URLs
   - Internal links

10. Security + Privacy
   - RBAC
   - Ownership checks
   - Rate limits
   - CAPTCHA/Turnstile
   - Secure cookies
   - Audit logs
   - Backups
   - Legal pages

11. Analytics
   - Search performed
   - Profile viewed
   - Slot selected
   - Appointment form started
   - Appointment submitted
   - WhatsApp CTA clicked
   - Appointment confirmed/cancelled/rescheduled

## Out of Scope for Phase 1

- Mobile app
- Full EMR/EHR
- AI diagnosis
- Medical advice chatbot
- Emergency care claims
- Public reviews/ratings unless verified completed appointments exist
- Online payment gateway
- Teleconsultation/video consultation
- Unofficial WhatsApp Web automation
- Discount/coupon/savings system

These modules match the Implementation Plan's final MVP scope and explicit out-of-scope list.

# Day 1 Decision Log

## Locked Decisions

1. Product type
   - Healthcare appointment discovery + assisted booking platform

2. MVP model
   - Hybrid booking
   - Patient selects preferred slot
   - Appointment remains Pending Confirmation until admin/partner approval

3. Positioning
   - Trust-first
   - Verified profiles
   - Clear appointment status
   - Assisted confirmation

4. Not allowed
   - Discounts
   - Coupons
   - Savings badges
   - Fake urgency
   - Fake reviews
   - Medical advice claims
   - Treatment guarantees
   - Emergency-care claims

5. Launch strategy
   - Start with one strong local market
   - Expand city-wise and speciality-wise after MVP proof

6. Technology stack
   - Next.js App Router
   - TypeScript
   - Tailwind CSS
   - PostgreSQL
   - Prisma
   - Auth.js/NextAuth
   - React Hook Form
   - Zod
   - Cloudinary/S3
   - GitHub
   - Vercel

7. Architecture
   - Service layer for business logic
   - Repository layer for database queries
   - RBAC and ownership checks
   - Audit logs
   - SEO-ready server-rendered public pages

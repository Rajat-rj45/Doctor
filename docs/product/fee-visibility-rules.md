# Fee Visibility Rules

## Purpose

Fee visibility should increase patient clarity without making MarizFirst look like a discount marketplace.

## Allowed Fee Display

Allowed:

- Consultation fee
- Fee range
- Starting consultation fee if verified
- "Fee available on request" when not confirmed
- "Consultation fee may vary by location/provider"

Not allowed:

- Discount price
- Strikethrough price
- 20% off
- Coupon code
- Savings badge
- Limited-time deal
- Cheapest doctor positioning
- Fake urgency pricing

## Doctor Fee Rules

Doctor profile may show consultation fee only if:

- Fee is provided by doctor/clinic/hospital
- Admin has verified it
- Fee has clear context
- It does not imply discount

## Hospital/Clinic Fee Rules

Hospital/clinic pages may show:

- Fee range
- Department-level fee if verified
- "Confirm fee during appointment support" if variable

## Copy Examples

Allowed:

- "Consultation fee: Rs. 800"
- "Fee range: Rs. 500-Rs. 1,200"
- "Fee may vary by doctor, department, or appointment type."
- "MarizFirst will help confirm appointment details."

Avoid:

- "Save 20%"
- "Best discount"
- "Lowest price guaranteed"
- "Offer valid today"

Backend Schema Document explicitly says no coupon logic is required for MVP; fees can be stored but no savings/coupon-led logic should drive the product.

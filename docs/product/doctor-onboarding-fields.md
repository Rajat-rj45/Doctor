# Doctor Onboarding Fields

## Basic Details

- Doctor name
- Slug
- Gender
- Profile image
- Phone
- Email
- Languages
- Short bio
- Publish status

## Professional Details

- Primary speciality
- Sub-speciality
- Qualification
- Experience years
- Registration number
- Medical council
- Designation
- Areas of expertise

## Location Details

- City
- Area
- Address
- Map URL
- Consultation location
- Linked hospital or clinic

## Fee and Availability

- Consultation fee
- Follow-up fee if available
- Slot duration
- Available days
- Available time ranges
- Slot capacity
- Appointment mode: clinic/hospital/in-person

## Media

- Profile image
- Clinic/hospital image if linked
- Gallery images if allowed
- Alt text for every image

## SEO Fields

- SEO title
- SEO description
- Canonical URL
- Schema type
- FAQ list
- Sitemap inclusion

## Verification Fields

- Registration number verified
- Qualification verified
- Phone/email verified
- Location verified
- Profile image approved
- No fake claim check
- No discount/coupon claim check

## Public Visibility Rules

Public profile should show:

- Name
- Speciality
- Qualification
- Experience
- Registration number if available
- Consultation fee if approved
- City/area
- Languages
- Available slots
- Verified badge
- Book Appointment CTA
- WhatsApp Support CTA

Public profile should not show:

- Private phone unless explicitly approved
- Private email
- Admin notes
- Partner notes
- Internal verification comments
- Patient data

Doctor profile fields should include qualification, experience, registration number, fee, location, slots, FAQ, and SEO schema according to the MVP requirements.

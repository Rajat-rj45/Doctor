# Clinic Onboarding Fields

## Basic Details

- Clinic name
- Slug
- Logo
- Cover image
- Short description
- Full description
- Publish status

## Location Details

- City
- Area
- Full address
- Landmark
- Map URL
- Postal code

## Contact Details

- Public phone if approved
- Admin contact person
- Admin phone
- Admin email
- Partner account owner

## Services

- Main services
- Specialities served
- Facility tags
- Consultation types
- Fee range if approved

## Doctors / Team

- Linked doctor name
- Speciality
- Experience
- Visibility status
- Available slots

## Availability

- Opening days
- Opening hours
- Slot duration
- Slot capacity
- Blocked dates

## Gallery

- Clinic exterior
- Reception
- Consultation room
- Equipment/services image if approved
- Alt text for every image

## SEO Fields

- SEO title
- SEO description
- Canonical URL
- Schema type
- FAQ list
- Sitemap inclusion

## Verification Checklist

- Address verified
- Contact verified
- Services verified
- Linked doctors/team verified
- Images approved
- No fake claim
- No fake review
- No discount/coupon positioning

Clinic profiles must support doctors/team, facilities, address, gallery, slots/CTA, and local discovery behavior.

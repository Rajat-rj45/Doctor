## Speciality Data Fields

Each speciality must include:

- Name
- Slug
- Short description
- Icon name
- SEO title
- SEO description
- Intro content
- FAQ content
- Publish status

## SEO URL Examples

- /specialities/dermatologist
- /doctors/dermatologist/gurgaon
- /doctors/general-physician/gurgaon

## Rules

- Do not add thin SEO pages without real content.
- Do not make medical guarantee claims.
- Do not write diagnosis/treatment advice as platform promise.
- Speciality pages should guide users to verified providers.

Why: PRD and TRD require speciality/city pages as SEO acquisition pages, with dynamic metadata, schema, canonical URLs, and internal linking.

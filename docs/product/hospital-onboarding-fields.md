# Hospital Onboarding Fields

## Basic Details

- Hospital name
- Slug
- Logo
- Cover image
- Short description
- Full description
- Publish status

## Location Details

- City
- Area
- Full address
- Landmark
- Map URL
- Postal code

## Contact Details

- Public phone if approved
- Admin contact person
- Admin phone
- Admin email
- Partner account owner

## Facilities

- Emergency availability label if verified
- OPD availability
- Diagnostics
- Pharmacy
- ICU
- Operation theatre
- Parking
- Insurance support
- Wheelchair access
- Other facility tags

## Linked Doctors

- Doctor name
- Speciality
- Department
- Visibility status
- Consultation location
- Appointment CTA behavior

## Gallery

- Exterior image
- Reception image
- OPD image
- Department image
- Other approved gallery images
- Alt text for every image

## SEO Fields

- SEO title
- SEO description
- Canonical URL
- Schema type
- FAQ list
- Sitemap inclusion

## Verification Checklist

- Address verified
- Contact verified
- Facilities verified
- Linked doctors verified
- Images approved
- No fake rating/review claim
- No treatment guarantee
- No discount/coupon claim

Hospital profiles must support facilities, specialities, linked doctors, address, gallery, and appointment CTA.
